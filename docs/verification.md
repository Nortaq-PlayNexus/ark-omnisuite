## Planning-window caveats
The web form accepts four UTC windows. UTC is entered explicitly; the browser does not determine the organizer’s local zone or resolve daylight-saving transitions. Adjacent windows are not conflicts. Discord timestamp tags are text only. The API accepts up to 20 offset-aware windows. The optional saved set is held in browser local storage and included in record backups; results are not saved. Compare-only leaves the saved set intact. A successful save replaces the previous set. Old backups without a saved set are accepted. No notifications are produced. Entered windows are sent to the app server for comparison. Discord tags have whole-second precision.

## Limits
No Dododex/A-Calc tame golden-value tests exist; the proposed tame engine was removed when its inputs and formulas could not be substantiated. Do not use this prototype to calculate taming costs. This is not an exhaustive research or production server-operations suite.
