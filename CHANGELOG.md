# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-11-23

### Added
- Initial public prototype release of ARK OMNISUITE.
- Obelisk Console web app (Python stdlib server + vanilla HTML/CSS/JS).
- Core calculators: ingot planner, mutation odds, breeding inheritance, forge fuel, crafting queue, raid readiness, tame ROI.
- Expedition Lab: The Island Broodmother tribute requirements and shortfalls.
- Incubation range mixer from user-provided temperatures.
- Waypoint route sketch for up to eight same-world pins (schematic grid distance).
- Operations Window Comparator with UTC overlap checks and Discord timestamp text.
- Local browser records: lost dinos, lineage, boss checklist, tame targets, waypoints, JSON backup/import.
- Experimental local RCON CLI (single-packet, simulated-server tested).
- Discord bot OMNI with calculation/help commands and `/plans` subcommands (dry-run/offline tests; live Discord not verified).
- Research and planning documents, verification notes, and screenshots.
