# Code of Conduct

## Our Pledge

We pledge to make participation harassment-free for everyone.

## Standards

Positive: respectful, constructive, evidence-based discussion, careful handling of security/server credentials.
Unacceptable: harassment, insults, publishing private information, encouraging unauthorized server access.

## Enforcement

Maintainers may remove/edit/reject contributions that violate this code.
